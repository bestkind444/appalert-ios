Why AppAlert

Built to match the exact alert you see inside leading Nigerian fintech apps.

I studied the toast, loading and confirm patterns from OPay, PalmPay and Moniepoint and rebuilt them precisely — same blur, same timing, same twelve-bar spinner — without pulling in a UI framework.

API reference

Four methods — that's the whole surface

MethodParametersDescription
toast(msg, duration?, type?)duration 2000–5000ms · type: success, error, defaultShows a centered toast that dismisses itself.
loading(msg?)msg defaults to "Loading..."Shows a loading card with the twelve-bar spinner.
hideLoading()—Dismisses the loading overlay.
confirm(options)title, message, confirmText?, cancelText?, onConfirm?, onCancel?, type?Shows a two-action confirm dialog.
Theming

Light or dark, your call

Every color is a CSS variable — override the ones you need.

LIGHT SURFACE CHECKLIST
  • Toast background — off-white with a soft border, not a hard shadow
  • Text at high contrast for accessibility
  • Spinner bars in a dark tone so they read on white
  • Confirm dialog — light card, dark primary action
css
:root{
  --appalert-bg: #ffffff;
  --appalert-text: #16181c;
  --appalert-overlay: rgba(10,12,10,.35);
  --appalert-success: #0d7a4f;
  --appalert-error: #e5484d;
  --appalert-radius: 16px;
}
